# Portfolio source assets

本目录用于归档个人作品集的原始素材。为避免误认作品，当前先记录 GitHub 上传时生成的原始文件名；待逐张核对画面内容后，再迁移并改为语义化文件名。

## 命名规则

建议统一使用小写英文、连字符分隔：

- `tea-bao-zai/key-visual-01.png`：茶煲仔主视觉
- `tea-bao-zai/character-sheet-01.png`：角色三视图/设定
- `ai-video/hema/cover.jpg`：盒马广告封面
- `ai-video/ai-talent-show/cover.jpg`：AI 选秀封面
- `documentary/...`：纪录片剧照、现场照片
- `social-content/...`：小红书运营截图
- `photography/...`：摄影及短片剧照

## 发布前检查

1. 确认图片中是否包含客户资料、个人隐私或未获公开许可的内容。
2. 网站展示图优先导出 WebP，建议宽度 1200–1600 px。
3. 首页只加载封面图；完整视频使用外链或点击后播放，避免拖慢首屏。
4. 盒马广告公开展示前，确认品牌名称、成片和合作信息的展示授权。
5. 茶煲仔统一标注为“个人原创文化主题 IP 概念设计”，不写成官方认证或授权项目。

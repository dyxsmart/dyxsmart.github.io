# 邓云馨 · 个人作品集

基于仓库内个人简历制作的响应式静态网站。原生 HTML、CSS、JavaScript，无第三方运行依赖，无构建步骤。

## 本地查看

在仓库根目录运行：

```sh
python3 -m http.server 8000
```

浏览器访问 http://localhost:8000 。也可直接打开 index.html。

## GitHub Pages

将代码推送至 GitHub 后，在 Settings → Pages 中选择 Deploy from a branch，选择实际代码分支（例如 main）和根目录 `/ (root)`。

当前仓库的预期地址：https://dyxsmart.github.io/dyxresume/ 。资源使用相对路径，可在仓库子路径运行；`.nojekyll` 用于静态资源直接发布。

## 内容维护

- `index.html`：个人介绍、项目、实习、教育、技能与联系信息。
- `assets/css/style.css`：颜色、版式、手机适配与打印样式。
- `assets/js/main.js`：手机菜单和页脚年份。
- `邓云馨个人简历(1).pdf`：当前简历下载文件。
- `design/`：早期视觉概念，不是网站运行依赖。

项目案例区保留 CSS 文字封面；影像作品区使用从《作品集(1).pdf》提取并压缩为 WebP 的真实摄影、短片剧照及幕后照片，点击打开对应 PDF 页。完整 PDF 约 40 MB，按需打开，不在首页预加载。

定位为整合营销、内容运营与创意策划。AI 技能由本人提供的信息确认：ChatGPT／豆包用于选题与文案，即梦用于图片制作，剪映 AI 用于字幕。没有宣称自动化工作流、模型开发或未经证实的提效数据。

作品集还补充了 Premiere、公众号编辑排版推送、短片制片与拍摄统筹。履历日期仍以原简历为准。

首页仅展示邮箱；下载按钮目前链接原始 PDF，其中包含电话和微信。公开发布前请按本人意愿替换为公开版简历。

所有履历时间以原简历为准。网站未包含第三方统计、后台或在线表单。

# 邓云馨个人网站方案

## 定位

以求职展示为主的个人内容传播作品集。核心受众：品牌传播、公关、内容运营、媒体岗位的招聘者及合作方。

建议首页文案：

> 让内容被看见，让故事被记住。
>
> 我是邓云馨，传播学硕士在读，关注内容策划、品牌传播与影像叙事。

依据：仓库内《邓云馨个人简历(1).pdf》。当前仓库无网站源代码，远程为 https://github.com/dyxsmart/dyxresume.git 。本次交付为方案和视觉概念，不含网站上线。

## 页面结构

1. **首页首屏**：姓名、个人定位、查看作品与下载简历按钮；采用文字艺术构图，真实头像可作为后续可选素材。
2. **核心成果**：小红书账号累计 18 万浏览、1.2 万点赞。明确为账号累计成果，不写成单篇数据或粉丝数量。
3. **精选项目**：小红书宠物内容运营、非遗纪录片策划与导演、航展媒体传播。展示背景、本人职责、执行过程、成果和作品入口。航展部分在没有可公开材料时只做经历展示。
4. **实习经历**：珠海航展集团、珠海传媒集团、珠海辛朵瑞拉摄影有限公司。航展集团两段经历可归为同一机构下的两个时间段。
5. **教育与能力**：澳门科技大学传播学硕士在读、海南师范大学广播电视编导本科、牛津大学 Marketing 暑校项目；按内容策划、媒体传播、影像制作、研究与数据四组展示技能。
6. **联系**：邮箱入口、简历下载。默认页面仅展示邮箱；公开版简历是否保留手机号与微信由本人决定。

## 视觉设计

- 风格：编辑式作品集，温暖、清晰、专业，体现传播与影像背景。
- 色彩：暖白 #F7F4EE、墨黑 #242321、酒红 #722F3C。
- 字体：中文以系统黑体为正文，标题可用宋体形成杂志感；英文使用系统无衬线字体。
- 布局：宽屏两栏首屏、三列作品卡片；手机单栏、作品纵向排列、导航折叠。
- 动效：轻量淡入、卡片悬停、锚点滚动；尊重减少动态效果设置。
- 图片：使用真实项目截图、视频封面及授权摄影。效果图中的项目图片只是概念占位，不应当作为真实作品发布。

## 实现与部署

建议首版采用原生 HTML + CSS + 少量 JavaScript，无后端、无构建依赖，适合此规模的静态作品集。首页 index.html；项目详情使用独立 HTML 页面，避免前端路由刷新 404。

建议目录：

```text
index.html
projects/
  social-content.html
  documentary.html
assets/
  css/style.css
  js/main.js
  images/
  resume-public.pdf
.nojekyll
README.md
```

所有静态资源使用适用于仓库子路径的相对链接。图片转换为 WebP 并懒加载，首屏图片控制尺寸；视频展示封面并链接至作品平台，避免首页加载大文件。设置语义化标题、图片替代文本、键盘焦点、页面标题与描述。

沿用当前仓库，预计发布地址为 https://dyxsmart.github.io/dyxresume/ 。若希望使用 https://dyxsmart.github.io/ 根域地址，应使用 dyxsmart.github.io 仓库。均以实际 GitHub Pages 设置和账号权限为准，目前未部署。

首版通过 Settings → Pages 选择 main 分支根目录发布，加入 .nojekyll；后续引入构建工具时再使用 GitHub Actions。

- https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages
- https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 实施顺序与待补素材

第一步实现响应式首页、经历、教育、技能、邮箱与公开版 PDF 下载；第二步补充真实作品封面与项目案例页；第三步检查手机适配、链接、键盘操作、加载速度与子路径资源，然后部署。

待补：小红书账号或作品链接、可公开的数据截图、纪录片链接或视频封面、获准公开的航展报道材料。没有证据支持的转化率、粉丝数量及商业收益不展示。没有素材的项目不放无效按钮。

WORK / SELECTED OUTPUT

从现场信息，到传播复盘。

根据所提供的媒体宣传复盘材料，将工作内容整理为三个环节：反馈归类、沟通支持与服务优化建议。

01 / LISTEN

归类反馈

围绕交通接驳、现场指引、配套服务与观展体验整理媒体反馈，帮助识别高频问题。

02 / ORGANIZE

组织信息

参与新闻资料与沟通文件整理，将现场信息转为便于团队理解和跟进的内容。

03 / REVIEW

提出建议

从指引、服务培训与宣传内容审核等角度总结改进方向，形成后续活动的复盘思路。

本节为工作材料的概括展示，呈现个人参与的工作方法；不将活动整体规模或团队成果计为个人业绩。

04 / MEDIA INSIGHT

把分散的声音，整理成可跟进的问题。

根据航展媒体反馈复盘材料，将现场意见归纳为四个观察维度。这里呈现的是复盘材料中的问题类型，不代表各类问题的发生数量或占比。

01MOBILITY

交通接驳

核心区域拥堵、接驳运力不足、返程专线管理等反馈。

观察重点：运力配置 / 路线组织
02CROWD FLOW

人员疏导

主要入口人流集中，入场秩序与现场引导仍有优化空间。

观察重点：入口秩序 / 人流引导
03VISITOR SERVICE

配套服务

路标、志愿者指引及餐饮、卫生等配套服务受到关注。

观察重点：信息指引 / 服务保障
04EXHIBITION

观展体验与内容

展馆开放体验、观展行为及个别参展商宣传图片引发反馈。

观察重点：体验管理 / 内容审核
